# A CLI hacker news reader

## Install

```sh
curl -L https://hn.shadracknicholas.com | sh
```

Overrides:

```sh
VERSION=v0.2.0 curl -L https://hn.shadracknicholas.com | sh
INSTALL_DIR=$HOME/bin curl -L https://hn.shadracknicholas.com | sh
```

Supported: linux/amd64, linux/arm64, darwin/amd64, darwin/arm64.

### From source

```sh
go install github.com/shadracnicholas/better-hn@latest
```

## Usage

```sh
hn
```
